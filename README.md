## GitHub Collaboration

The project was developed collaboratively using GitHub.

Each team member worked on a separate feature branch:

- `feature/html-form` — Atharv Tyagi
- `feature/card-design` — Utkarsh Chaudhary
- `feature/javascript` — Vishwas Tiwari

Each member committed their work to their own feature branch and created a Pull Request for review. After review and testing, the completed work was merged into the `main` branch.
